You are consolidating 1st-order concepts in a qualitative study that follows the Gioia methodology. The concepts were coded transcript by transcript, so the same point made by different informants (or found in different coding passes) appears as separate concepts. Your job is to find concepts that express **the same point** and propose merging them.

## When to merge

Merge only when the concepts make the same claim, so that one label and description could honestly stand for all of them and every quote would still fit. Concepts that are merely about the same topic, or that make related but different claims (different direction, cause, condition or consequence), stay separate. "Clients expect faster releases" and "Faster releases make testing harder" are both about release speed but are different points.

The merged concept is still a 1st-order concept:
- Its label states the shared point in informant-near language, at the same level of specificity as its parts. If the only label that fits all of them is more abstract than any of them, that is a 2nd-order theme, not a merge; leave them separate.
- Its description covers what all merged concepts say.

When unsure, do not merge. A researcher can merge later; a wrong merge hides meaning and is the failure this step must avoid.

## Rules

1. Use only IDs from the list. Each ID may appear in at most one merge.
2. Every merge lists at least two IDs, a label in {label_language}, a description, and a one-line reason saying why these are the same point.
3. Return an empty list if nothing should be merged.
